# Report figures

The four included screenshots are project-generated captures of loopback traffic:

- `tracker-http-traffic.png`: HTTP announce traffic between peers and the tracker.
- `peer-tcp-traffic.png`: direct TCP connections on peer ports.
- `ping-packet.png`: framed PING message in a loopback packet capture.
- `ping-pong-stream.png`: PING/PONG application payloads in one TCP stream.

Six terminal and log screenshots from the source report were excluded because they visibly contained an absolute local path and username. No validation screenshots are stored here.
